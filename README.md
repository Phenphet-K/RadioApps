RadioApp - โปรแกรมเล่นสื่ออัตโนมัติ

โปรแกรมจัดการและเล่นสื่อ (Audio & Video) อัตโนมัติ พัฒนาด้วย Python (Tkinter + VLC) เหมาะสำหรับใช้ในงานกระจายเสียงวิทยุภายในองค์กร โรงเรียน หรือห้างสรรพสินค้า ที่ต้องการตั้งเวลาเปิด-ปิดเพลงหรือเสียงประกาศแบบอัตโนมัติ
ออกแบบและพัฒนาโดย:  นายเพ็ญเพชร ไกรทอง
# ฟีเจอร์หลัก (Features)
 ระบบตั้งเวลาเล่นอัตโนมัติ (Scheduler): ตั้งเวลาเปิด-ปิด สื่อหลัก และไฟล์คั่นรายการ (Jingles/Announcements) ได้อย่างอิสระ
 ระบบโฟลเดอร์แยกตามวัน (Daily Folders): สามารถตั้งค่าโฟลเดอร์เพลงแยกตามวัน (จันทร์ - อาทิตย์) โปรแกรมจะเปลี่ยนรายการสื่อให้อัตโนมัติตามวันปัจจุบัน
 โหมดการเล่นหลากหลาย: รองรับการเล่นแบบสุ่ม (Random) และเล่นเรียงลำดับ (Sequential) รวมถึงฟังก์ชันเล่นวนซ้ำ (Loop)
 ระบบเสียง VLC Engine: แกนหลักใช้ VLC Media Player รองรับไฟล์สื่อได้หลากหลายรูปแบบ (MP3, MP4, WAV, AVI, ฯลฯ) พร้อมระบบ Equalizer ปรับแต่งเสียงได้ 10 Bands
 Drag & Drop: ลากและวางไฟล์ลงในตารางรายการเพื่อเพิ่มสื่อได้อย่างง่ายดาย
 Resume Playback: ระบบจดจำการเล่น หากโปรแกรมปิดตัวกะทันหัน สามารถกลับมาเล่นต่อจากวินาทีเดิมได้
 System Tray & Auto Start: ซ่อนโปรแกรมลงมุมจอ (Tray) ได้ และรองรับการเปิดโปรแกรมอัตโนมัติเมื่อเปิดเครื่อง (Auto-start)
 Auto Shutdown: ตั้งเวลาให้ปิดคอมพิวเตอร์อัตโนมัติหลังจากเล่นสื่อจบรายการได้
# มีอะไรใหม่ในเวอร์ชัน 1.9 (Release Notes)
การอัปเดตครั้งนี้เน้นเพิ่มความเสถียรของระบบ (Bug Fixes) และปรับปรุงโครงสร้างไฟล์เพื่อความยืดหยุ่นในการปรับแต่ง:
 New Config System: เพิ่มโฟลเดอร์ `config/` สำหรับเก็บไฟล์ตั้งค่า เช่น `logo.png` เพื่อให้ผู้ใช้สามารถปรับเปลี่ยนโลโก้หน้าโปรแกรมได้เองโดยไม่ต้อง Build โค้ดใหม่
 Dashboard Reset Fix: ปรับปรุงปุ่ม "รีเซ็ตการตั้งค่า" ให้ล้างข้อมูลการเลือกโฟลเดอร์รายวัน (จันทร์-อาทิตย์) ในหน้าแดชบอร์ดให้กลับเป็นค่าเริ่มต้นอย่างสมบูรณ์
 Improved Scheduler Stability: แก้ไขข้อผิดพลาด (AttributeError) ในระบบตรวจสอบวันข้ามคืน ทำให้โปรแกรมรันต่อเนื่องแบบ 24/7 ได้เสถียรขึ้น
 UI Interaction Fix: แก้ไขข้อผิดพลาด (KeyError: 'popdown') ขณะใช้งาน Mouse Wheel เลื่อนผ่าน Dropdown Menus
 Optimized Build Structure: ปรับปรุงไฟล์ `.spec` สำหรับ PyInstaller เป็นแบบ One-Directory เพื่อแก้ปัญหา VLC ค้นหา Plugins ไม่พบ และช่วยให้โปรแกรมเปิดได้รวดเร็วขึ้น
การติดตั้งและใช้งาน (Installation)
# สำหรับผู้ใช้งานทั่วไป (End User):
1. ดาวน์โหลดไฟล์ติดตั้ง `Setup_RadioApp_v1.9.exe` 
2. ทำการติดตั้งตามขั้นตอน
3. เปิดโปรแกรมจาก Shortcut บน Desktop
4. หากต้องการเปลี่ยนโลโก้โปรแกรม ให้นำรูปภาพมาตั้งชื่อว่า `logo.png` และนำไปวางทับในโฟลเดอร์ `C:\Program Files (x86)\RadioApp\_internal\config\`
ระบบจะสร้างไฟล์และโครงสร้างโฟลเดอร์ Directory
 โครงสร้างไฟล์สำคัญ (Project Structure)
*   `radio.py` - โค้ดหลักของโปรแกรม
*   `vlc-64/` - ไดเรกทอรีเก็บไลบรารีและ Plugins ของ VLC
*   `config/` - ไดเรกทอรีสำหรับเก็บไฟล์ภาพ `logo.png`
*   `fonts/` - ไดเรกทอรีสำหรับเก็บฟอนต์ TH Sarabun New
*   `icon.ico` - ไอคอนของโปรแกรม
